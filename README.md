# HSdeck Voyage To The Sunken City 카드 API

`cards.json`과 `render.json`은 기존 HS Plus 카드 정보를 기반으로 하며, `art/`는 설치된 클라이언트의 원화입니다. `golden/`은 해당 카드의 원본 황금 원화 재질·애니메이션·텍스처입니다. 날짜별 과거 원화나 황금 효과를 보장하지 않습니다.


## 공개 API 및 편집 규칙 (2026-11-14)

- `cards.json`: 카드 ID/현재 목록. `data/<CARD_ID>.json`: 카드별 최초 한국 사용일 및 날짜별 능력·효과 변경. `art/`, `golden/`, `frame/`: 일반·황금 카드 그림, 애니메이션, 프레임·재질·텍스처/셰이더의 원본 파일입니다.
- 중복 `render.json`, `history.json`, `cards-date.json`, `render-date.json`, `history-date.json`은 배포 대상이 아니며 Git에 재커밋하지 않습니다. 빌드 검증용으로만 임시 생성할 수 있습니다. 불필요한 schema/호환 래퍼를 추가하지 않습니다.
- 카드별 파일이 날짜 키 형식이 아니라면 근거·전체 필드를 보존해 변환한 후 사용해야 합니다. 최초 날짜는 실제 한국 대전 가능일이며 베타 북미 시간 환산, 모험 지구 개방, 이벤트 실개시일과 토큰 생성 가능일을 구분합니다.
- 잘못된 기존 최초 날짜를 삭제한 뒤 통합하고, 이후 기록은 달라진 필드만 입력합니다. 표시용 줄바꿈은 `<br></br>`. 원시 자료·황금 원화·프레임 바이너리는 손대지 않습니다.
- 생성·검증에 필요한 `release-policy.json`, `.github/`, `tools/`의 실제 참조는 확인 후에만 삭제합니다.
